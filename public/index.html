Anything you add shows up here as soon as it is built, and you can read it right in the browser — no reader needed. There are four ways to get content in:

  • News and blogs Add an RSS feed; each refresh builds one EPUB of the latest articles.
  • Your own files Drop a PDF or a saved web page, or paste article URLs.
  • Something you write Type or paste into the editor and build it into a book.
  • Free books Browse Standard Ebooks — public-domain classics, properly typeset.

Have an Xteink reader? Converting works offline. Sync Reader needs the reader awake with File Transfer open on its screen — so the usual order is add everything first, then connect and sync once.

                Each page becomes a picture, so layout is preserved exactly and text cannot reflow or be resized on the reader. Splitting applies to PDFs; text size applies to web pages and drafts. Pages are written as JPEG — the reader needs far less free memory to decode JPEG than PNG, and refuses PNGs mid-render when memory is tight, leaving blank boxes.

                  Getting the reader ready
                  1. On the Xteink, open File Transfer and join your Wi-Fi.
                  2. The screen shows an IP address — put it in Reader address if crosspoint.local doesn't resolve.
                  3. Keep the Mac on the same network, then hit Sync Reader.

                  Hotspot mode instead: on the reader choose the hotspot option, join CrossPoint-Reader from your Mac's Wi-Fi menu, then click Hotspot above (or enter 192.168.4.1). Note that your Mac has no internet while joined to the reader, so convert pages and URLs before switching over — sending works fine either way.

                  The reader only serves uploads while that screen is open. Files land in the app’s own folders — /A-pub Books, /A-pub Notes and /A-pub Feeds — and appear in your library.

                  No usable network? Copy via the SD card

                  Some networks (campus, guest and hotel Wi-Fi) stop devices talking to each other, so the reader can be online yet unreachable. Two ways round it, neither needing a network:

                  1. Reader's own hotspot — see above. Works on every model.
                  2. SD card in a reader — eject the microSD card from the reader, put it in a card reader, then set Send via to that drive. Works on every model.

                  Connecting the X4 to a computer by USB does not work for file transfer — it is an ESP32-C3 whose USB port is serial/JTAG only. (The USB Drive option exists in the firmware but only on the USB-OTG models: X4 Pro, X4C and Paper Mono.) Books land in the same folder however they arrive, so the reader's library looks identical either way.
